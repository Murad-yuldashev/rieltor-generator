# Phase 4.2 — Lead purchase + wallet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the exclusive lead claim from 4.1 cost money — a realtor pays the lead's `priceSom` out of a prepaid wallet balance (topped up via a test-payment stub), debited atomically inside the claim transaction.

**Architecture:** A `Wallet` (cached `balanceSom`) + a `WalletTransaction` ledger. Top-up credits the balance (preset packages, no gateway). The 4.1 `LeadsService.claim` gains an in-transaction debit: it locks the wallet row (`SELECT ... FOR UPDATE`, after the lead row lock), checks the balance, and either debits + records a `LEAD_CLAIM` + claims the lead (all-or-nothing) or throws 402 and leaves the lead OPEN. Same transactional-lock discipline 3.3b used for the rating aggregate.

**Tech Stack:** NestJS 11 · Prisma 6 · PostgreSQL 16 · Zod (`@rieltor/shared`) · React 19 · Vite · Tailwind v4 · React Router 7 · TanStack Query 5 · Feature-Sliced Design.

**Spec:** `docs/superpowers/specs/2026-08-30-phase-4.2-lead-purchase-design.md`

- [ ] **Step 1: `ensureWallet` (idempotent).** In `wallet.service.ts`:

```ts
/** Create the realtor's wallet on first touch (idempotent under the unique userId). */
private async ensureWallet(userId: string): Promise<void> {
  try {
    await this.prisma.wallet.upsert({
      where: { userId },
      create: { userId, balanceSom: 0n },
      update: {},
    });
  } catch (e) {
    // A concurrent create raced us; the row now exists — ignore the unique violation.
    if (!(e instanceof Prisma.PrismaClientKnownRequestError && e.code === 'P2002')) throw e;
  }
}
```

- [ ] **Step 2: `view`.**

```ts
async view(userId: string): Promise<WalletView> {
  await this.ensureWallet(userId);
  const wallet = await this.prisma.wallet.findUnique({
    where: { userId },
    select: { balanceSom: true, transactions: { orderBy: { createdAt: 'desc' }, take: 50, select: { id: true, type: true, amountSom: true, leadId: true, createdAt: true } } },
  });
  return {
    balanceSom: String(wallet!.balanceSom),
    transactions: wallet!.transactions.map((t) => ({ id: t.id, type: t.type, amountSom: String(t.amountSom), leadId: t.leadId, createdAt: t.createdAt.toISOString() })),
  };
}
```

- [ ] **Step 3: `topup`** — an atomic increment (no lock needed; the `increment` is atomic) + a ledger row, in one transaction:

```ts
async topup(userId: string, packageId: 'p100' | 'p300' | 'p500'): Promise<WalletView> {
  await this.ensureWallet(userId);
  const pkg = TOPUP_PACKAGES.find((p) => p.id === packageId);
  if (!pkg) throw new BadRequestException('Noto‘g‘ri paket');
  const amount = BigInt(pkg.amountSom);
  await this.prisma.$transaction(async (tx) => {
    const w = await tx.wallet.update({ where: { userId }, data: { balanceSom: { increment: amount } }, select: { id: true } });
    await tx.walletTransaction.create({ data: { walletId: w.id, type: 'TOPUP', amountSom: amount } });
  });
  return this.view(userId);
}
```

- [ ] **Step 4: `debitForClaim` (the `tx`-scoped helper — Task 4 calls it inside the claim tx).** The wallet must already exist (Task 4 calls `ensureWallet` first); this locks the wallet row, re-reads the balance under the lock, checks, debits:

```ts
async debitForClaim(tx: Prisma.TransactionClient, userId: string, amountSom: bigint, leadId: string): Promise<void> {
  // Lock the realtor's wallet row so concurrent claims serialize and cannot over-spend.
  await tx.$queryRaw`SELECT 1 FROM "Wallet" WHERE "userId" = ${userId} FOR UPDATE`;
  const wallet = await tx.wallet.findUnique({ where: { userId }, select: { id: true, balanceSom: true } });
  if (!wallet || wallet.balanceSom < amountSom) {
    throw new HttpException("Balans yetarli emas — hisobingizni to'ldiring", 402);
  }
  await tx.wallet.update({ where: { userId }, data: { balanceSom: { decrement: amountSom } } });
  await tx.walletTransaction.create({ data: { walletId: wallet.id, type: 'LEAD_CLAIM', amountSom, leadId } });
}
```
