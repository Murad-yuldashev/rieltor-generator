# Phase 3.2 — Client presentations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a realtor's 3.1 collection into a shareable immutable client presentation — a public `/p/:token` page (SSR + og-preview) showing the curated listings with client-facing per-item notes, per-listing view analytics (opens + dwell), and a `t.me/share` Telegram deep-link. C3 + C4 + C5.

**Architecture:** Backend first (3 Prisma models → shared DTOs → `presentations` API module with a public token-gated read/ingest + RealtorGuard-scoped create/list/analytics, plus the 3.1-reserved `CollectionItem.note` editor). Then the public page in `apps/web` (SsrController `p/:token` + og-meta, mirroring `obj/:id`; a `/p/:token` SPA route with an IntersectionObserver/sendBeacon analytics client). Then the `apps/agent` cabinet (item-note editor + create/share + "Mening taqdimotlarim" analytics). Public endpoints are unauthenticated, token-gated, and NOT subscription-gated so sent links keep working.

**Tech Stack:** NestJS 11 · Prisma 6 · PostgreSQL 16 · Zod · React 19 · Vite 6 · Tailwind v4 · React Router 7 · TanStack Query 5 · Feature-Sliced Design.

**Spec:** `docs/superpowers/specs/2026-08-27-phase-3.2-presentations-design.md`

```ts
private url(token: string): string {
  const base = this.config.get('PUBLIC_BASE_URL', { infer: true });

/** Snapshot an owned collection into an immutable presentation. */
async present(realtorId: string, collectionId: string): Promise<PresentationCreateResult> {
  const collection = await this.prisma.collection.findUnique({
    where: { id: collectionId },
    include: { items: { orderBy: { position: 'asc' } } },
  });
  if (!collection || collection.realtorId !== realtorId) throw new NotFoundException();
  if (collection.items.length === 0) throw new BadRequestException("Kolleksiya bo'sh");
  const presentation = await this.prisma.presentation.create({
    data: {
      realtorId,
      token: createId(),            // a second cuid — use the same id generator Prisma uses (see Step 2a)
      title: collection.name,
      sourceCollectionId: collectionId,
      items: {
        create: collection.items.map((it) => ({ listingId: it.listingId, position: it.position, note: it.note })),
      },
    },
    select: { id: true, token: true },
  });
  return { id: presentation.id, token: presentation.token, url: this.url(presentation.token) };
}
```
