# Phase 2.1: AI foundation, valuation & wizard AI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Introduce the Gemini AI provider and ship the flagship seller-capture entry point — a free "Uyingiz qancha turadi?" valuation — plus AI description generation and voice input in the listing wizard.

**Architecture:** A single `GeminiService` in the API wraps Google Gemini (official `@google/generative-ai` SDK). Valuation is a **hybrid**: a deterministic median price/m² computed from PUBLISHED listings (grouped by district + room bucket), turned into an estimate range, with a short Uzbek explanation generated by Gemini. Description generation is a guarded endpoint. Voice input is a pure frontend Web Speech API feature. Everything reuses the Phase 1 client, FSD layering, and desktop/`desk:` rules.

**Tech Stack:** NestJS 11 · Prisma 6 · Zod · `@google/generative-ai` · React 19 · Vite 6 · Tailwind v4 · TanStack Query 5 · FSD

**Spec:** `docs/superpowers/specs/2026-08-21-platform-spec.md` (§3.3 A21/A6, §3.2 A4, §6.2, §7 Phase 2). Provider = **Google Gemini** (2026-08-24 decision); valuation = hybrid median + Gemini explanation (chosen because only ~18 listings exist — a pure comparables model is unreliable; the median approach degrades gracefully and improves as inventory grows).

## Global Constraints

- Code in English only — identifiers, routes, comments. All user-facing copy is Uzbek.
- Do not write automated tests unless asked. Verify with lint, typecheck, curl, and a real browser check. Keep the existing suites green (web 34/34, shared 18/18, API unit 37 + e2e 22).
- Below 1440px nothing changes without an explicit decision; every desktop style is under `desk:`.
- Global `api` prefix: controllers use bare paths, frontend fetch keeps `/api`.
- FSD boundaries ESLint-enforced: `app → pages → widgets → features → entities → shared`; a widget/entity may not import a feature except a widget may.
- The shared client is `apiGet(path, schema)` / `apiPost(path, schema, body?)` / `apiPatch` / `apiDelete` / `apiUpload` with `fetchWithAuth` (Phase 1). Reuse it; there is no `apiFetch`.
- **Gemini calls must degrade gracefully:** if the API key is missing or Gemini errors/times out, valuation still returns the numeric estimate (explanation falls back to a templated Uzbek sentence), and description generation returns a clear 503-style error the UI can show — never a 500 crash.
- Dev DB is `rieltor_p1` (18 seeded PUBLISHED listings). `apps/api/.env` holds secrets; `yarn seed` needs env exported.

```ts
import { GoogleGenerativeAI } from '@google/generative-ai';
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
export class GeminiService {
  private readonly logger = new Logger(GeminiService.name);
  private readonly client = process.env.GEMINI_API_KEY
    ? new GoogleGenerativeAI(process.env.GEMINI_API_KEY)
    : null;

  /** Returns the model's text, or null if AI is unavailable / errored. Never throws. */
  async generate(prompt: string, opts?: { maxTokens?: number }): Promise<string | null> {
    if (!this.client) return null;
    try {
      const model = this.client.getGenerativeModel({
        model: process.env.GEMINI_MODEL ?? 'gemini-1.5-flash',
        generationConfig: { maxOutputTokens: opts?.maxTokens ?? 512 },
      });
      const result = await model.generateContent(prompt);
      return result.response.text().trim();
    } catch (error) {
      // A provider outage must never take down a request — the caller falls back.
      this.logger.warn(`Gemini generate failed: ${String(error)}`);
      return null;
    }
  }
}
```

- [ ] **Step 1: Shared schemas**

Append to `packages/shared/src/schemas.ts`:

```ts
export const ValuationRequestSchema = z.object({
  district: z.string().min(2),
  rooms: z.number().int().min(0).max(20).nullable(),
  areaM2: z.number().positive().max(10_000),
  type: ListingTypeSchema,
});

export const ValuationResultSchema = z.object({
  estimateSom: z.string(), // BigInt-as-string, like priceSom
  lowSom: z.string(),
  highSom: z.string(),
  perM2Som: z.string(),
  /** How many PUBLISHED listings backed the median — drives a confidence hint. */
  comparablesCount: z.number().int(),
  explanation: z.string(),
});
export type ValuationRequest = z.infer<typeof ValuationRequestSchema>;
export type ValuationResult = z.infer<typeof ValuationResultSchema>;
```

- [ ] **Step 2: Service — deterministic median first**

Create `apps/api/src/valuation/valuation.service.ts`. Method `estimate(req)`:

1. Load PUBLISHED listings of the same `type` in the same `district`; if `rooms` is non-null, prefer the same room bucket, else fall back to the whole district, else the whole `type`. Track `comparablesCount` at the level actually used.
2. Compute the median **price per m²** from those listings (`Number(priceSom) / areaM2` each, sort, median). If zero comparables, fall back to a global median per m² for that type.
3. `perM2 = median`; `estimate = round(perM2 * req.areaM2)`; `low = round(estimate * 0.9)`; `high = round(estimate * 1.1)`.
4. Ask Gemini for a 2–3 sentence Uzbek explanation:

```ts
const prompt = `Sen O'zbekiston ko'chmas mulk bo'yicha yordamchisan. Quyidagi taxminiy narxni 2-3 gapda, do'stona va sodda o'zbek tilida tushuntir. Raqamlarni takrorlama, faqat nega shu oraliq ekanini ayt (tuman, xona soni, maydon, bozor holati). Tuman: ${req.district}, xona: ${req.rooms ?? 'ko'rsatilmagan'}, maydon: ${req.areaM2} m², taxmin: ${estimate} so'm.`;
const explanation = (await this.gemini.generate(prompt, { maxTokens: 256 }))
  ?? `Ushbu taxmin ${req.district}dagi o'xshash e'lonlarning o'rtacha m² narxiga asoslangan. Aniq narx holat, qavat va ta'mirга qarab farq qilishi mumkin.`;
```

5. Return all fields as strings for the BigInt-like ones (`.toString()`), `comparablesCount`, `explanation`.

- [ ] **Step 3: Controller (public — no auth; this is the top-of-funnel)**

Create `apps/api/src/valuation/valuation.controller.ts`:

```ts
import { Body, Controller, Post } from '@nestjs/common';
import { ValuationRequestSchema } from '@rieltor/shared';
import { ValuationService } from './valuation.service';

@Controller('valuation')
export class ValuationController {
  constructor(private readonly valuation: ValuationService) {}

  @Post()
  estimate(@Body() body: unknown) {
    return this.valuation.estimate(ValuationRequestSchema.parse(body));
  }
}
```

- **Spec coverage:** A21 (valuation) Tasks 2–3; A6 (AI description) Tasks 4–5; A4 (voice) Task 6; §6.2 AI provider Task 1. A22/A25/A30 (owner cabinet, reverse listings, price history) are **Plan 2.2**; the Telegram bot (A5) is **Plan 2.3** — separate subsystems, each independently shippable.

- **No hard AI dependency:** every AI touch has a non-AI fallback, so Phase 2.1 is fully usable before a Gemini key is provisioned.
