# Phase 3.3a — Public realtor profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public realtor microsite at `/r/:slug` (SSR + og) with branded profile (logo, colour, verified badge) + auto-updating published-listings catalogue; a MODERATOR-set verification badge; and the marketplace seller display connected to real realtor profiles. C1 (path-based site generator) + C14 (verified profile; rating → 3.3b).

**Architecture:** Backend first (RealtorProfile additions → shared DTOs → the listings-mapper seller-resolution + query includes → public `GET /api/r/:slug` → verification endpoint → profile slug/brandColor/logo). Then `apps/web` (the `/r/:slug` public page served via `NotFoundShellFilter` exactly like `/p/:token`; the marketplace seller badge/link; a minimal moderator verify page). Then `apps/agent` (the branding editor). The seller resolution is additive + defaults to today's `Agent` for any non-published-realtor listing; the public page is not subscription-gated.

**Tech Stack:** NestJS 11 · Prisma 6 · PostgreSQL 16 · Zod · React 19 · Vite 6 · Tailwind v4 · React Router 7 · TanStack Query 5 · FSD.

**Spec:** `docs/superpowers/specs/2026-08-27-phase-3.3a-realtor-public-profile-design.md`

- [ ] **Step 1: Extend `ListingRow` + a resolver in `mapper.ts`.** Make `owner` optional so callers without the include still work:

```ts
type OwnerWithProfile = {
  role: string;
  name: string | null;
  phone: string;
  photoUrl: string | null;
  realtorProfile: {
    agency: string;
    slug: string | null;
    verified: boolean;
    logoUrl: string | null;
  } | null;
};
export type ListingRow = Listing & {
  agent: Agent;
  images: Pick<Image, keyof ImageDto>[];
  owner?: OwnerWithProfile | null;
};

/** The seller shown publicly: the real realtor when the owner is a published REALTOR, else the default Agent. */
function resolveSeller(row: ListingRow) {
  const o = row.owner;
  const p = o?.realtorProfile;
  if (o?.role === 'REALTOR' && p?.slug) {
    return {
      id: row.agent.id, // keep the Agent id (schema shape unchanged)
      name: o.name ?? 'Rieltor',
      agency: p.agency,
      photoUrl: p.logoUrl ?? o.photoUrl ?? row.agent.photoUrl,
      phone: o.phone, // masked by the callers via maskPhone
      telegram: row.agent.telegram, // telegram CTA stays the Agent's for now
      verified: p.verified,
      profileSlug: p.slug,
    };
  }
  return {
    id: row.agent.id,
    name: row.agent.name,
    agency: row.agent.agency,
    photoUrl: row.agent.photoUrl,
    phone: row.agent.phone,
    telegram: row.agent.telegram,
    verified: false,
    profileSlug: null,
  };
}
```
