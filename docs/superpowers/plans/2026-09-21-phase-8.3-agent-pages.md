# Phase 8.3 — Agent Cabinet Pages: Desktop Layout + Widgets + Seed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every agent (realtor) cabinet page a desktop internal layout + richer client-derived widgets, and add the realtor seed that makes the cabinet reachable and populated — mirroring the just-merged Phase 8.2 CRM treatment.

**Architecture:** Presentational redesign of ten in-cabinet React pages (`@rieltor/agent`, FSD, React 19 + Vite + React Router 7 + TanStack Query 5), regrouping data the pages already fetch into responsive layouts (card grids, `lg:grid` main + sticky-aside, `StatTile` rows) and deriving richer stats client-side. Plus one additive, idempotent Prisma seed block (`seedRealtorCabinet`) — the shared prerequisite that unlocks both cabinet guards. No backend/DTO/schema change.

**Tech Stack:** React 19, React Router 7, Tailwind v4 (`@theme` tokens, agent teal `#0d9488` already set), TanStack Query 5, FSD; apps/api Prisma 6 seed (TypeScript, BigInt money).

**Spec:** [docs/superpowers/specs/2026-09-21-phase-8.3-agent-pages-design.md](../specs/2026-09-21-phase-8.3-agent-pages-design.md) — the plan argues from the spec; executors read both.

## Global Constraints

- Code/identifiers/comments **English**; UI copy **Uzbek** (keep every existing Uzbek string; reuse existing label constants — do not re-author).
- **No new test files.** Verify each task with the root turbo command: `yarn turbo run typecheck lint build --filter=@rieltor/agent --filter=@rieltor/api` (run from the worktree root; NEVER `yarn workspace <pkg> lint` — exit 127). Task 1 additionally runs the seed twice for idempotency. Editing existing fixtures is allowed.
- **No backend/DTO/schema/migration change, no new deps, no chart library.** Every widget is derived client-side from data the page already loads or from the new seed. All bars/meters are pure CSS.
- **Teal accent unchanged.** Bars/chips/badges use `bg-accent`/`bg-accent-soft`/`text-accent` (agent teal); status tones use `brand-green`/`brand-amber`/`brand-rose`. Never the web funnel's `#6d28d9` or the CRM blue.
- **Phone (<768) layout stays visually intact** — only `md`/`lg`/`desk` tiers are added. Where a page splits into main + aside, preserve phone reading order with the `contents` wrapper + `order-*` trick (as 8.2 did). `order-*` controls VISUAL order only, not DOM/tab order — the live smoke measures reorder via `getBoundingClientRect().top`, never `innerText`.
- **`StatTile` is an agent-local copy** at `apps/agent/src/shared/ui/stat-tile/` — never cross-import from `apps/crm` (FSD boundary → lint/build fail). It resolves against agent's own `@/shared/lib/cn` (exists) and identical brand tokens.
- **BigInt money is a string end-to-end.** Sum with `BigInt(...)` accumulation, never `Number()`; read a balance's sign with `.startsWith('-')`. Money literals in the seed use underscore separators + `n` suffix (`200_000n`).
- **Seed is additive + idempotent**, guarded on `prisma.subscription.count() > 0`, with fixed string ids; runs AFTER `seedDeveloperCrm(prisma)` (real FKs into CRM units/complexes).
- **The page renders exactly ONE `<main>`.** `CabinetShell` already supplies the centred `bg-surface` container + `<Outlet/>` (Phase 8.1 stripped the old `max-w` wrappers) — do not add another container.
- `apps/web`, `apps/crm`, and all other apps are **not touched** (agent's own `StatTile` copy aside).

```tsx
import type { LeadOutcomeStage, LeadStats } from '@rieltor/shared';
import { cn } from '@/shared/lib/cn';

const FLOW_STAGES: Exclude<LeadOutcomeStage, 'LOST'>[] = ['NEW', 'CONTACTED', 'MEETING', 'WON'];

const STAGE_LABEL: Record<LeadOutcomeStage, string> = {
  NEW: 'Yangi',
  CONTACTED: "Bog'lanildi",
  MEETING: "Ko'rik",
  WON: 'Bitim',
  LOST: "Yo'qotildi",
};

/**
 * Lead conversion funnel — pure-CSS horizontal bars over `leadStats.funnel`
 * (NEW→CONTACTED→MEETING→WON) with a rose LOST tail and a null-safe win-rate line.
 * Each bar's width is its share of the largest flow stage. Teal accent only.
 */
export function LeadPipelinePanel({
  stats,
  className,
}: {
  stats: LeadStats | undefined;
  className?: string;
}) {
  const funnel = stats?.funnel;
  const maxFlow = funnel ? Math.max(1, ...FLOW_STAGES.map((s) => funnel[s])) : 1;
  // winRate is a 0..1 FRACTION (WON/(WON+LOST)); null when no resolved leads.
  const winRate =
    stats == null || stats.winRate == null ? '—' : `${Math.round(stats.winRate * 100)}%`;

  return (
    <section className={cn('rounded-card bg-card p-5 shadow-card', className)}>
      <div className="flex items-baseline justify-between gap-3">
        <h2 className="text-[15px] font-bold text-ink">Leadlar voronkasi</h2>
        <span className="text-[13px] font-semibold text-ink-2">
          G'alaba: <span className="text-[15px] font-extrabold text-ink">{winRate}</span>
        </span>
      </div>

      {funnel == null ? (
        <p className="mt-3 text-[14px] text-ink-3">Yuklanmoqda...</p>
      ) : (
        <>
          <ul className="mt-4 flex flex-col gap-2.5">
            {FLOW_STAGES.map((stage) => {
              const count = funnel[stage];
              const percent = Math.min(100, Math.max(0, (count / maxFlow) * 100));
              return (
                <li key={stage} className="flex items-center gap-3">
                  <span className="w-24 shrink-0 text-[13px] font-semibold text-ink-2">
                    {STAGE_LABEL[stage]}
                  </span>
                  <span className="h-2.5 flex-1 overflow-hidden rounded-full bg-accent-soft">
                    <span
                      className="block h-full rounded-full bg-accent transition-[width]"
                      style={{ width: `${percent}%` }}
                    />
                  </span>
                  <span className="w-8 shrink-0 text-right text-[13px] font-extrabold text-ink">
                    {count}
                  </span>
                </li>
              );
            })}
          </ul>

          <div className="mt-2.5 flex items-center gap-3 border-t border-line pt-2.5">
            <span className="w-24 shrink-0 text-[13px] font-semibold text-brand-rose">
              {STAGE_LABEL.LOST}
            </span>
            <span className="h-2.5 flex-1 overflow-hidden rounded-full bg-brand-rose/10">
              <span
                className="block h-full rounded-full bg-brand-rose transition-[width]"
                style={{ width: `${Math.min(100, (funnel.LOST / maxFlow) * 100)}%` }}
              />
            </span>
            <span className="w-8 shrink-0 text-right text-[13px] font-extrabold text-ink">
              {funnel.LOST}
            </span>
          </div>
        </>
      )}
    </section>
  );
}
```

```tsx
function WalletKpis({ transactions }: { transactions: WalletTxRow[] }) {

        tone="green"
      />
      <StatTile label="Amaliyotlar soni" value={String(transactions.length)} />
    </StatTileRow>
  );
}
```
